This collection features packet capture (PCAP) files generated from TLS handshakes using various Post-Quantum Cryptographic (PQC) Key Encapsulation Mechanisms (KEMs) and signature algorithms within our 5G network environment. 
These captures are valuable for research, protocol analysis, and interoperability testing of quantum-resistant TLS implementations.

Each file follows the naming convention:
kem_<KEM_NAME>_sign_<SIGNATURE_NAME>*.pcap
